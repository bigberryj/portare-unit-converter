## Final settings

Enabled; floating bottom-right only; inches initially; remember enabled; one decimal; 20 px offset; 8 px radius; background `#173942`, text `#ffffff`. Header/footer remain available to select. Tests restore these defaults through the normal settings UI.

## Scope and remaining limits

Images/PDFs, unlabelled numbers, measurement components split across HTML text nodes, feet compounds, area/volume, signed and thousands notation are not converted. Editable/input values are excluded. Current quote integration was verified; arbitrary third-party widgets deriving logic from visible labels need separate integration tests. GitHub Actions CI and automatic updates were not added. The settings preview is static, not live.
