# 0.1.2 per-unit label verification

## Feature

Settings → Portare Unit Converter now includes separate text fields for the inch and centimetre button states. Original `Units: in` / `Units: cm` remain defaults. Both live preview samples and every frontend placement/shortcode/fallback use the configured text. Accessible names retain explicit current/next units. Plain-text sanitization, blank fallback and Unicode-safe 60-character bounds prevent hidden or injected labels; longer wording wraps on small screens.

## Preservation caveat

The fresh baseline contained **710 authored records** and **4,961 relevant metadata rows**. Authored post-content and existing gallery/quote option snapshots matched after testing. The broader metadata hash differed, although its row count was unchanged. The baseline retained an aggregate metadata hash rather than per-row values, so the changed metadata cannot be attributed reliably from this evidence. This plugin registers no authored-content/commerce writes; no old metadata snapshot was restored and no claim that all metadata remained identical is made.

QA authentication cookies and the helper session are removed/revoked after verification. No customer quote submission or outbound staging integration was exercised. The test contexts were isolated from the user's normal browser.
